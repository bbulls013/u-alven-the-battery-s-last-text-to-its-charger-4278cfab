## What it does

`main.py` writes one line of plain text (153 characters) to
`/output/entry.txt`: the phone battery's final message to the charger it
waited for all day. The output is fixed, so every run produces byte-identical
text.

## Run

```sh
python3 main.py
cat /output/entry.txt
```
